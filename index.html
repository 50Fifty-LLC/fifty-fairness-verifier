How this works

Every FiftyFifty prediction game commits a 32-byte server seed at creation. The hash SHA256(serverSeed) is published immediately so the server can't change the seed later. Both players also contribute a 64-char hex client seed. The game outcome is derived from these inputs: 

HMAC_SHA256(
  key   = serverSeed,
  data  = `${fairnessVersion}|${gameId}|${creatorSeed}|${opponentSeed}|${purposeTag}:${counter}`
)

Counter starts at 0 and increments per 32-byte block. Bytes from the stream are read big-endian and turned into uniform integers via mask-and-reject (no modulo bias). Purpose tags differ per game type:

  • number-guess:target
  • tile-reveal:board:creator and tile-reveal:board:opponent
  • blackjack:deck
  • plinko:balls, plinko:sudden, plinko:tiebreak

At settlement, the server seed is revealed — the same 32 bytes whose hash was published before play. Anyone can then re-run the algorithm and confirm the outcome wasn't altered after the fact.
